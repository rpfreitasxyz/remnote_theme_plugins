# Antigravity Dark Theme for RemNote

A dark theme for RemNote inspired by the focused aesthetic of Google Antigravity IDE.
It features deep space backgrounds, electric blue accents, clear typography, and harmonized highlights designed for comfortable, distraction-free study and writing sessions.

## Visual Highlights

A visualização do tema inclui:

- **Superfícies em Camadas:** Fundo do editor em cinza profundo (`#1f1f1f`) com barras laterais e cabeçalhos em tom contrastante suave (`#181818`).
- **Acentos Antigravity:** Azul vibrante (`#0078d4`) aplicado em links, referências, badges e botões primários.
- **Tipografia Nítida:** Hierarquia visual limpa com títulos destacados, código inline em tom terracota (`#ce9178`) e blocos com bordas sutis.
- **Flashcards Otimizados:** Delimitadores de cartões (`->`, `<->`, `::`) destacados em azul e cartões elevados com sombra suave para foco na revisão.
- **Paleta de Destaques:** Cores de marcação (vermelho, laranja, amarelo, verde, azul e roxo) calibradas para excelente contraste em modo escuro.
- **Barras de Rolagem Minimalistas:** Estilo discreto e translúcido que desaparece quando inativo.

## Como Instalar

Você pode instalar o tema de duas maneiras no RemNote:

### Método 1: Como Plugin de Tema (Recomendado)

O processo de instalação via pacote de tema segue os seguintes passos:

1. Baixe o arquivo `antigravity-remnote-theme.zip` (ou compacte os arquivos `manifest.json`, `theme.css` e `README.md` da pasta `antigravity`).
2. Abra o RemNote no seu computador ou navegador.
3. Acesse **Settings (Configurações) > Plugins and Themes**.
4. Clique na aba **Build**.
5. Clique no botão **Upload Theme** (ou **Upload Plugin**) e selecione o arquivo `.zip`.
6. Certifique-se de que o modo escuro do RemNote está ativado (**Settings > Theme > Dark**).

### Método 2: Pelo Powerup Custom CSS

Para aplicar diretamente via CSS personalizado sem empacotar:

1. Abra o RemNote.
2. Pressione `Ctrl + P` (ou `Cmd + P` no Mac) para abrir o menu de comandos.
3. Digite e selecione **Custom CSS**.
4. Clique no botão **Add Blank CSS Block**.
5. Abra o arquivo `theme.css` deste repositório, copie todo o seu conteúdo e cole no bloco de código criado.
6. Dê o nome "Antigravity Dark Theme" ao bloco e ative-o.
